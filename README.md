## 这一版

电脑端三栏工作台（左起盘、中图盘、右页签）。平板两栏，手机图盘优先。

- 命：占星（热带/恒星）、流年、合盘、阿拉伯点、印占、七政四余、八字（十神·藏干·刑冲合害·大运）、紫微十二宫、皇极/铁板/河洛
- 卜：奇门九宫格局、六壬天地盘、太乙、三式、六爻（64 卦辞）、风水八宅、塔罗 78 张、地占、金口、太玄
- 工具：黄历、天文馆（亮星+二十八宿）、类象、名人库
- 玄学史：人物、编年、天象、源流、故事、原典（《天官书》《灵宪》《系辞》《葬书》《乙巳占》《渊海子平》《滴天髓》《步天歌》等）

解盘在本机规则，不走网络。覆盖安装旧版即可，本地命例还在。
