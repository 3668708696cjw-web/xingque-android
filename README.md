# 星阙 · 本地离线安卓版

命盘、八字、紫微、奇门、六壬、六爻、黄历、星空、塔罗、玄学史。全部在手机上算，不登录，不联网。

## 下载 APK

打开 **[Releases](https://github.com/3668708696cjw-web/xingque-android/releases/latest)**，点最新的 `Xingque-offline-*.apk`。

当前版本 **v1.1.0**：

https://github.com/3668708696cjw-web/xingque-android/releases/download/v1.1.0/Xingque-offline-1.1.0.apk

## 装了什么

- 命：占星（热带/恒星）、流年、合盘、阿拉伯点、印占、七政四余、八字、紫微、皇极/铁板/河洛
- 卜：奇门、六壬、太乙、三式、六爻（64 卦辞）、风水八宅、塔罗 78 张、地占、金口、太玄
- 工具：黄历、天文馆（亮星+二十八宿）、类象、名人库
- 玄学史：76 人、59 条编年、18 篇原典（《天官书》《灵宪》《系辞》《葬书》《乙巳占》《渊海子平》《滴天髓》《步天歌》《四书》等）

解盘在本机规则，不走网络。

## 安装

1. 下载 APK
2. 允许「从此来源安装」
3. 桌面出现「星阙」

自签名侧载。命例只存在这台手机。

包名 `app.xingque.offline` · Android 6+

整合自开源项目 [Horosa-APP](https://github.com/Herakleios/Horosa-APP) 与 [Horosa-Web-App](https://github.com/Horace-Maxwell/Horosa-Web-App-comprehensively-improved-Windows)。
