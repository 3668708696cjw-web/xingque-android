# 星阙 · 本地离线安卓版

命盘、八字、紫微、奇门、六壬、六爻、黄历、星空、塔罗、玄学史。全部在手机上算，不登录，不联网。

## 下载 APK

打开 **[Releases](https://github.com/3668708696cjw-web/xingque-android/releases/latest)**，点 `Xingque-offline-1.0.0.apk` 即可下载。

直链：

https://github.com/3668708696cjw-web/xingque-android/releases/download/v1.0.0/Xingque-offline-1.0.0.apk

## 安装

1. 下载后打开文件
2. 允许「从此来源安装」
3. 桌面出现「星阙」

自签名侧载，系统或 Play 保护可能提示一次，选仍然安装即可。命例只存在这台手机。

- 包名 `app.xingque.offline`
- Android 6 及以上
- 约 3.8 MB

整合自开源项目 [Horosa-APP](https://github.com/Herakleios/Horosa-APP) 与 [Horosa-Web-App](https://github.com/Horace-Maxwell/Horosa-Web-App-comprehensively-improved-Windows)。
